# To-Do List Life Dashboard

## Features
- **Greeting** Time-of-day greeting (Morning / Afternoon / Evening / Night) + live clock |
- **Focus Timer** 25-min countdown with Start, Stop, and Reset |
- **To-Do List** Add, edit, mark done, delete tasks — saved in Local Storage |
- **Quick Links** Add / remove favorite website shortcuts — saved in Local Storage |

### Additional Features
- **Light / Dark mode** — toggle button in the header, preference saved  
- **Custom name in greeting** — set your name via a modal, saved to Local Storage  
- **Change Pomodoro time** — enter any duration (1–120 min) and apply
- **Sort tasks** (A→Z, Z→A, Done-last) 
- **Prevent duplicate tasks** are also included
