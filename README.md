# 🗂️ To-Do List Life Dashboard

A clean, minimal life dashboard built with **HTML, CSS, and Vanilla JavaScript**.  
No frameworks. No backend. Everything lives in your browser's Local Storage.

## ✨ Features

### MVP
| Feature | Details |
|---|---|
| **Greeting** | Time-of-day greeting (Morning / Afternoon / Evening / Night) + live clock |
| **Focus Timer** | 25-min countdown with Start, Stop, and Reset |
| **To-Do List** | Add, edit, mark done, delete tasks — saved in Local Storage |
| **Quick Links** | Add / remove favorite website shortcuts — saved in Local Storage |

### Challenges (3 of 5)
- 🌙 **Light / Dark mode** — toggle button in the header, preference saved  
- ✏️ **Custom name in greeting** — set your name via a modal, saved to Local Storage  
- 🔁 **Change Pomodoro time** — enter any duration (1–120 min) and apply  

> Bonus: **Sort tasks** (A→Z, Z→A, Done-last) and **Prevent duplicate tasks** are also included.

- HTML5
- CSS3 (CSS Custom Properties for theming)
- Vanilla JavaScript (ES6+)
- Browser `localStorage` API
